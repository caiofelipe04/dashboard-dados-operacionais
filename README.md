# dashboard-dados-operacionais
 Dashboard de Indicadores Operacionais | Business Intelligence  Desenvolvimento de projeto de BI para visualização e análise de indicadores operacionais, utilizando Google Sheets e Looker Studio, com o objetivo de facilitar o acompanhamento de métricas e apoiar a tomada de decisões.  Tecnologias: Google Sheets, Looker Studio e HTML/CSS.
